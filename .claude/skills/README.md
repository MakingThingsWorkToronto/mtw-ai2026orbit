# Local design skills

Read [Design and content](../../docs/design.md) and its authoritative briefs. The user's selected styles and current scope override generic skill defaults.

| Skill | Use |
| --- | --- |
| [AI slop check](ai-slop-check/SKILL.md) | Detect generic patterns and departures from the selected visual source. |
| [Impeccable](impeccable/SKILL.md) | Apply the requested design workflow with its bundled playbooks and tools. |
| [Blender assets](blender-web-assets/SKILL.md) | Author and inspect reusable dimensional geometry, materials and exports. |
| [Immersive storytelling](immersive-storytelling/SKILL.md) | Compose meaningful connections, camera motion and readable scene pauses. |

Both design review skills are mandatory for the requested design work. Read only the playbooks relevant to the active task. Asset generation and passing technical checks do not establish visual acceptance.

Canonical packages live in .codex/skills. Matching full packages in .agents/skills and .claude/skills provide native discovery. Keep all three copies identical after an intentional skill edit. The original repository's skills remain unchanged.
